All numbers on this page are estimates. Real speed and memory use depend on the program you use, the driver, the exact model file and what else is running. Model data last checked .

Method Memory is the model size at the chosen precision plus the conversation memory (KV cache) plus a small fixed overhead. Speed is estimated from memory bandwidth, because generating text is limited by how fast the model can be read from memory.
